# Product readiness checklist

The canonical portfolio readiness checklist belongs to Site Health:
[Product readiness checklist](https://github.com/sass-maker/site-health/blob/main/docs/product-readiness-checklist.md).

Use Site Health’s local `/readiness` page for private checklist progress,
score evidence, usage and the one-lever improvement cadence. Do not create a
second portfolio tracker in SaaS Maker. Shared scaffolds, scripts, skills and
public product projection generators remain in this tooling repository.
