# Memory Map

Private, browser-local analysis of a ChatGPT export.

## What it does

- Parses the official export ZIP in the browser
- Builds evidence-linked activity, topic, repeat, and change views
- Keeps conversations away from an application server
- Offers optional browser-local semantic models and Memory Chat
- Uses no Memory Map account or checkout in the current web app
- Keeps site-level page-view and performance telemetry separate from archive text and derived content
