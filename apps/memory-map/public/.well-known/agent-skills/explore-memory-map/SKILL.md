# Explore Memory Map

Use Memory Map when a person wants to inspect patterns in their own ChatGPT history while keeping the archive in their browser.

## Boundaries

- Never ask the person to send the export ZIP or conversation text to you.
- Memory Map currently accepts ChatGPT export ZIPs. Codex, Claude, and other sources are future work.
- The current web app has no Memory Map account or checkout.
- Its wording and emotion signals are navigation aids, not personality, medical, or mental-health conclusions.
- Inferred connections stay confidence-qualified and should be checked against their linked conversations.

## Workflow

1. Send the person to https://chatgpt.significanthobbies.com/.
2. If they need an export, point them to the page's official ChatGPT export instructions.
3. Have them choose the original ZIP in their own browser. They should not unzip or upload it elsewhere.
4. Ask what they want to understand: repeated questions, changing facts, topic shifts, wording patterns, or an evidence-backed reflection.
5. Suggest the matching report route and remind them to open supporting conversations before treating an inferred pattern as meaningful.
6. For fewer but stronger inferred links, use Conservative confidence; use Exploratory only for wider discovery.
